# Security policy

`gbc-to-md` is an experimental offline toolchain/runtime project and does not expose a network service by itself.

If you find a security-sensitive issue in repository scripts, build tooling, dependency bootstrap, or generated target behavior, avoid publishing exploit details in a public issue before the maintainer has had a reasonable opportunity to assess it. Use GitHub's private vulnerability reporting feature when it is enabled for this repository.

For ordinary crashes, compatibility bugs, or build failures, use the normal bug-report issue template.

Do not include proprietary ROM data, secrets, credentials, or private save data in reports.

# Third-party software and provenance

This repository contains an experimental target runtime and backend that consume C generated by external projects. Third-party dependencies are **not vendored** in Git; pinned versions are downloaded into `.deps/` by the bootstrap scripts.

## GB Recompiled / `gbrecomp`

- Project: `arcanite24/gb-recompiled`
- Pinned release: `v0.1.0`
- License: MIT
- Purpose here: static recompilation of the synthetic Game Boy fixtures into C.

The Linux release archive checksum is pinned in `versions.env` and verified during bootstrap.

## SGDK

- Project: `Stephane-D/SGDK`
- Pinned tag: `v2.11`
- Purpose here: Mega Drive runtime/library, VDP/input/SRAM APIs, linker script, and official SEGA mapper support.

SGDK remains an external dependency and keeps its own license and notices.

## m68k-elf GCC toolchain

- Project used by the Linux bootstrap: `iratahack/m68k-elf-gcc`
- Pinned release: `v14.2.0_latest`
- Purpose here: cross-compiling the SGDK target for Motorola 68000.

## ROM policy

No commercial Game Boy/Game Boy Color ROM is included. Every `.gb` used by the test suite is generated locally from original fixture-generator code under `fixtures/` and is ignored by Git.

# Third-party software and provenance

This repository contains an experimental target runtime and backend that consume C generated by external projects. Native bootstrap dependencies are not vendored in Git. Browser toolchain assets are also fetched from pinned external packages during CI/Pages builds rather than committed to this repository.

## GB Recompiled / `gbrecomp`

- Project: `arcanite24/gb-recompiled`
- Pinned release: `v0.1.0`
- License: MIT
- Purpose here: static recompilation of Game Boy / Game Boy Color ROM bytes into generated C.

The Linux release archive checksum is pinned in `versions.env` and verified during native bootstrap. The browser pipeline builds the same pinned recompiler core with Emscripten.

## SGDK

- Project: `Stephane-D/SGDK`
- Pinned tag: `v2.11`
- Purpose here: Mega Drive runtime/library, VDP/input/SRAM APIs, linker script, and official SEGA mapper support.

SGDK remains an external dependency and keeps its own license and notices.

## Native m68k-elf GCC toolchain

- Project used by the Linux bootstrap: `iratahack/m68k-elf-gcc`
- Pinned release: `v13.2.0_latest`
- Purpose here: native/CI cross-compiling of the SGDK target for Motorola 68000.

## Browser m68k GCC/binutils toolchain

- Package: `romdev-toolchain-m68k-gcc`
- Upstream repository: `monteslu/romdev`
- Pinned package version: `0.3.0`
- License declared by the package: GPL-3.0-or-later, with the GCC Runtime Library Exception applying to the bundled GCC runtime components
- Purpose here: WebAssembly builds of `cc1-m68k`, `m68k-elf-as`, `m68k-elf-ld`, `m68k-elf-objcopy`, related Genesis build glue, and a browser-injectable SGDK build pipeline.

The toolchain's GPL applies to the compiler/toolchain itself; using the compiler does not by itself impose the GPL on generated ROMs. The upstream package also contains SGDK-derived material with its own licensing/provenance. Browser deployments must preserve the applicable third-party notices and provide the corresponding source/provenance required by those licenses.

This repository does not copy those WebAssembly binaries into Git. CI installs the exact package version recorded in `versions.env`; the final Pages packaging step should stage the package assets and notices from that pinned dependency.

## ROM policy

No commercial Game Boy/Game Boy Color ROM is included. Every `.gb` used by the automated test suite is generated locally from original fixture-generator code under `fixtures/` and is ignored by Git.

The browser playground processes user-selected ROM bytes locally. Users are responsible for using ROMs they are legally entitled to use.
